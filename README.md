MERIDIAN CAYS: an open-world crime game across five islands joined by causeways and ferries. A four-person crew (Mara, Nia, Sol, Marek) runs nine named story missions while MCPD pursuit escalates from patrols to PIT maneuvers, roadblocks, helicopters, and marine police, with district standing, street races, and a save system. Built by an AI agent for make.fun's "Make GTA 6" bounty, $1,666 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a browser.
